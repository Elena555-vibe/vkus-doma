# Вкус дома

Мобильная PWA-книга рецептов на русском языке. В личной книге сохраняются рецепты, фотографии, избранное и заметки; общая книга предназначена для базовых рецептов владельца.

## Локальный запуск

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```

## Что работает

- адаптивный интерфейс, категории, поиск, избранное и пересчёт порций;
- создание, редактирование и удаление личных рецептов;
- дробные количества (`0,5`, `1/2`, `½`) и единицы измерения, включая `°C`;
- загрузка фотографии, заметки к общим рецептам и Web Share с копированием ссылки;
- PWA-манифест и офлайн-кэш интерфейса;
- вход по email и паролю, облачное хранение рецептов, фото, избранного и заметок на PHP/MySQL.

До создания личной книги рецепты остаются в браузере. При первой регистрации приложение переносит эти локальные рецепты, заметки, избранное и доступные фотографии в личную книгу.

## Структура

- `src/main.tsx` — маршруты и интерфейс;
- `src/lib/store.ts` — временное локальное хранение и миграция;
- `src/lib/cloud.ts` — клиент облачного API;
- `server/api/index.php` — PHP API;
- `server/schema.sql` — схема MySQL;
- `server/api/config.example.php` — образец закрытой серверной конфигурации.

`server/api/config.php` и загруженные фотографии намеренно исключены из Git.

## Защита данных и обновления

- На Timeweb включены резервные копии файлов; отдельно должен работать ежедневный дамп MySQL через `server/api/backup.php`.
- Дампы записываются вне публичной папки, хранятся 31 день и не доступны по URL.
- Изменения структуры базы добавляются только новыми файлами в `server/migrations/`; перед применением всегда делается свежий дамп.
- Перед выпуском обновления: резервная копия → проверка новой сборки → публикация → проверка входа, рецепта, фото и заметки. Откат выполняется только из копии, без ручного удаления работающей базы.

## Развёртывание на Timeweb

Сборка опубликована в отдельной подпапке основного сайта. Для нового окружения нужно:

1. выполнить `pnpm build`;
2. разместить содержимое `dist` вместе с `server/api` и `server/schema.sql`;
3. создать отдельную MySQL-базу, импортировать `schema.sql`;
4. создать `server/api/config.php` по примеру, указав закрытые данные MySQL;
5. создать доступную веб-серверу папку `uploads` рядом с `api`;
6. включить HTTPS — без него установка PWA на телефон недоступна.

Перед публичным запуском нужны политика обработки данных, страница восстановления пароля, подтверждение email и назначение владельца общей книги. Пароли хранятся только как криптографические хэши; секреты базы не попадают в репозиторий.
