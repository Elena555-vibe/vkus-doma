# Вкус дома

Локальный MVP русскоязычной кулинарной книги в эстетике домашнего Прованса.

## Запуск

`pnpm install` · `pnpm dev` · `pnpm check` · `pnpm build`

## Что работает

Общая книга, каталог с поиском и категориями, детальный рецепт и пересчёт порций, избранное, заметки, создание/редактирование/удаление личных рецептов, загрузка локального фото, подсказки ингредиентов, особый сценарий полуфабрикатов, share/clipboard fallback, 404 и адаптивная навигация.

Данные живут в `localStorage`; профиль демонстрационный. Нет SMS-входа, сервера, синхронизации, защищённого хранения и настоящих публичных ссылок — они потребуют backend, базы данных, хранилища изображений и юридических документов оператора.

## Структура

`src/data` — типы и seed-данные; `src/lib/store.ts` — локальный репозиторий; `src/main.tsx` — маршруты и UI; `src/styles` — токены и глобальные стили; `public/images` — оригинальные изображения блюд.

## Timeweb deployment

Перед публикацией: подключить репозиторий, установить build-команду `pnpm build`, каталог `dist`, включить SPA fallback на `index.html`, проверить технический домен и SSL, затем подключить домен. Актуальные настройки перед деплоем сверять с документацией Timeweb.
