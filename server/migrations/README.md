# Миграции базы «Вкус дома»

Каждое изменение структуры базы добавляется новым SQL-файлом с возрастающим номером: `0002_…sql`, `0003_…sql` и т. д.

- Не редактируйте уже применённые миграции.
- Перед применением новой миграции запускается резервная копия базы.
- Миграции должны быть совместимыми: добавлять поля и таблицы безопасно, не удалять пользовательские данные.
- После применения фиксируйте номер миграции в журнале развёртывания.

Текущая рабочая база была создана по `../schema.sql`. Следующая структурная правка будет добавлена отдельной миграцией, а не изменением исходной схемы.
