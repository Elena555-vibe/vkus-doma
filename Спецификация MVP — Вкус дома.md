# Спецификация MVP «Вкус дома»

## 1. Назначение продукта

«Вкус дома» — русскоязычная веб-кулинарная книга с проверенными семейными рецептами. Пользователь получает доступ к общей базовой книге, ведёт личные рецепты, сохраняет избранное и передаёт свои рецепты другим людям по ссылке.

Первая версия рассчитана на семью и друзей, но регистрация открыта каждому, у кого есть адрес сайта.

## 2. Цели MVP

- Дать пользователю удобный доступ к общим семейным рецептам.
- Позволить безопасно хранить личные рецепты в своей книге.
- Быстро находить рецепт по названию.
- Давать возможность передать личный рецепт и сохранить полученную копию.
- Создать эмоционально тёплый интерфейс в эстетике прованса.

## 3. Роли и права

| Роль | Возможности |
|---|---|
| Гость без входа | Не используется в MVP: для работы с книгой нужна регистрация. |
| Пользователь | Просматривает общую книгу, добавляет/редактирует/удаляет личные рецепты, ведёт избранное, добавляет заметки к общим рецептам, делится личными рецептами. |
| Администратор | Добавляет, редактирует и удаляет общие рецепты; управляет категориями, общим справочником ингредиентов и просматривает список пользователей. |

## 4. Авторизация

- Вход и регистрация — по номеру телефона с подтверждением одноразовым SMS-кодом.
- Пользователь принимает условия использования и политику конфиденциальности до завершения регистрации.
- Профиль содержит номер телефона и действие «Выйти».
- Уведомления в MVP не предусмотрены.

## 5. Навигация

Нижнее мобильное меню состоит из четырёх разделов:

1. **Общая книга** — общие рецепты, сгруппированные по категориям.
2. **Мои рецепты** — созданные пользователем и сохранённые из полученных ссылок.
3. **Избранное** — один общий список избранных рецептов.
4. **Профиль** — данные пользователя и выход.

Кнопка «Добавить рецепт» находится внутри раздела «Мои рецепты», а не в нижнем меню.

## 6. Категории общей книги

Категории отображаются на главном экране сразу после красивой заставки:

1. Завтраки
2. Закуски
3. Супы
4. Салаты
5. Горячее
6. Гарниры
7. Соусы
8. Выпечка
9. Десерты
10. Напитки
11. Заготовки
12. Полуфабрикаты

Теги наподобие «быстро», «без мяса» и «на праздник» в MVP не входят.

## 7. Карточка рецепта

В списке рецептов отображаются только:

- фотография или фирменная заглушка;
- название;
- категория.

Внутри полного рецепта отображаются:

- название;
- фото;
- категория;
- автор, если он указан;
- количество порций;
- общее время приготовления;
- ингредиенты;
- пошаговое приготовление;
- заметки пользователя;
- действия «В избранное» и «Поделиться».

## 8. Данные рецепта

### Общие поля

- Название — обязательно.
- Главная фотография — необязательна.
- Категория — обязательна.
- Автор — необязателен для личных рецептов; для общих рецептов заполняется администратором, когда известен автор.
- Количество порций — обязательно.
- Общее время приготовления — обязательно.
- Ингредиенты — обязательны.
- Шаги приготовления — обязательны.

### Ингредиенты

Каждый ингредиент содержит:

- наименование;
- числовое количество;
- единицу измерения.

Единицы выбираются только из списка: `г`, `кг`, `мл`, `л`, `шт.`, `ст. л.`, `ч. л.`, `стакан`.

При вводе наименования пользователь получает подсказки из общего справочника ингредиентов. Справочник различает конкретные продукты, например «лук репчатый» и «лук зелёный». Если нужного ингредиента нет, пользователь может создать свой вариант для рецепта; администратор при необходимости добавляет его в общий справочник.

### Порции и пересчёт

Пользователь выбирает число порций, а количества всех ингредиентов автоматически пересчитываются пропорционально. Исходные порции рецепта хранятся как базовое значение.

### Приготовление

- Рецепт состоит из упорядоченных, пронумерованных шагов.
- У каждого шага указывается время выполнения.
- Отдельно хранится общее время приготовления.
- Таймер в MVP не требуется.

### Полуфабрикаты

Для категории «Полуфабрикаты» вместо обычного единого приготовления обязательно показываются два блока:

1. **Подготовка и заморозка**.
2. **Приготовление после разморозки**.

Также для них обязательны поля «Срок хранения» и «Условия хранения».

## 9. Общие и личные рецепты

### Общие рецепты

- Создаются и обновляются только администратором.
- Доступны всем зарегистрированным пользователям.
- Пользователь не может изменить текст, фото, ингредиенты, автора или шаги общего рецепта.
- Пользователь может добавить только личное поле **«Заметки к рецепту»** — например, «в следующий раз добавить меньше сахара».
- Заметки видны исключительно этому пользователю.

### Личные рецепты

- По умолчанию видны только автору.
- Пользователь полностью редактирует и удаляет свои рецепты.
- Фото можно загрузить, заменить и обрезать перед сохранением.
- Если фото отсутствует, используется фирменная заглушка «Вкус дома».
- При создании собственного рецепта пользователь может указать автора или оставить поле пустым.

## 10. Избранное и поиск

- У пользователя один список избранных без папок и коллекций.
- В избранное можно добавить общие и личные рецепты.
- Поиск работает по названию рецепта.
- Фильтры по ингредиентам, времени и другим параметрам не входят в MVP.

## 11. Передача рецептов

Пользователь может поделиться только личным рецептом.

### Получатель с приложением

1. Открывает ссылку.
2. Видит страницу предпросмотра рецепта.
3. Нажимает «Сохранить в мою книгу».
4. Получает независимую личную копию, которую затем может редактировать.

### Получатель без приложения

- Открывает красивую адаптивную веб-страницу рецепта.
- Страница не индексируется поисковыми системами.
- PDF в MVP не создаётся.

### Удаление и ссылки

- После удаления исходного личного рецепта ссылка перестаёт работать.
- Рецепт, который получатель уже сохранил в свою книгу, остаётся у него как независимая копия.
- Ссылки не имеют срока действия и не отзываются отдельно от удаления рецепта.

## 12. Визуальное направление

Стиль — тёплый, домашний прованс без чрезмерного декора:

- основной фон: молочно-кремовый;
- акценты: лавандовый, шалфейный, приглушённый оливковый;
- основные кнопки: мягкая терракота;
- фактуры: лён, матовая бумага, лёгкая природная текстура;
- детали: деликатные соцветия лаванды в подложке, не мешающие чтению;
- фотографии блюд — основной визуальный центр;
- фирменная заглушка без фото: название «Вкус дома» и ненавязчивый знак на тематическом фоне.

Приоритет адаптации: мобильный экран → планшет → компьютер.

## 13. Технические требования MVP

- Русский язык интерфейса.
- Формат: адаптивное веб-приложение с возможностью установить его как приложение на телефон.
- После первого открытия общие рецепты доступны без интернета: их данные и изображения сохраняются локально.
- Данные, добавленные или изменённые без сети, синхронизируются после восстановления соединения.
- База данных, хранилище фотографий и резервные копии размещаются в России.
- Личные рецепты и заметки защищены авторизацией и недоступны другим пользователям без явной передачи ссылки.
- Регулярное резервное копирование обязательно.

## 14. Юридический минимум

В MVP включаются:

- политика конфиденциальности;
- условия использования;
- отдельное согласие на обработку номера телефона при регистрации;
- правило об ответственности пользователя за права на загружаемые фотографии и публикуемое описание рецепта;
- механизм удаления аккаунта и связанных личных данных.

Номер телефона относится к персональным данным; согласие пользователя должно быть конкретным и подтверждаемым, а оператор должен уметь подтвердить факт его получения. ## 15. Не входит в MVP

- Публикация пользовательских рецептов в общую книгу.
- Семейные группы и совместный доступ.
- Комментарии и оценки.
- Уведомления.
- Коллекции и папки избранного.
- Поиск по ингредиентам и сложные фильтры.
- Калорийность, аллергены, состав и нутриенты.
- Таймер приготовления.
- Несколько фотографий процесса.
- PDF-экспорт.
- Другие языки.
- Индексация личных рецептов поисковиками.

## 16. Критерий готовности MVP

MVP готов, если новый пользователь может зарегистрироваться по телефону, открыть общую книгу без интернета после первого посещения, найти рецепт по названию, добавить его в избранное, создать свой рецепт с фото и ингредиентами, оставить личную заметку к общему рецепту и передать личный рецепт другому человеку по ссылке.
