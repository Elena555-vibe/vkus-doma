# Безопасная публикация «Вкус дома» на Timeweb

Этот порядок обязателен для всех обновлений приложения. Он не изменяет MySQL-базу, папку `uploads`, пользователей, рецепты, заметки или избранное.

## Что защищает процесс

- Пользовательская книга хранится отдельно от фронтенд-сборки: обновление HTML/CSS/JS не удаляет рецепты.
- PWA не перезагружается сама во время заполнения формы. При появлении новой версии пользователь видит кнопку «Обновить» и сам выбирает момент.
- Каждый выпуск имеет новые имена JavaScript- и CSS-файлов, поэтому после обновления не смешиваются старый и новый код.
- Перед выпуском существует свежая резервная копия базы и ежедневный автоматический дамп.

## Единственный порядок публикации

1. Убедиться, что рабочее дерево не содержит не относящихся к выпуску изменений.
2. Выполнить проверку типов: `pnpm check`.
3. Собрать версию именно для рабочего домена из корня: в PowerShell задать `VITE_APP_BASE=/`, затем выполнить `pnpm build`.
4. Проверить локальную сборку: открываются главная, рецепт, форма, профиль; тестовые данные не создаются в рабочей базе.
5. Упаковать **содержимое** `dist` в временный архив.
6. Загрузить архив в Timeweb и распаковать только в папки статической части сайта `~/vkus-doma-domain` и `~/vkus-doma-domain/public_html`.
7. Не загружать архив в `~/public_html/vkus-doma/api`, кроме временного помещения файла; после распаковки архив удаляется. Никогда не заменять `config.php`, `uploads` или файлы базы.
8. Открыть `https://vkus-doma-recepty.ru/?update=<номер-коммита>`: параметр предотвращает проверку по старой кэшированной странице. Проверить новый хеш файла `assets/index-*.js` и ключевые сценарии.
9. Открыть приложение обычным способом: при старой установленной PWA должно появиться предложение «Доступна новая версия приложения». После нажатия «Обновить» — актуальная версия.
10. Только после проверки сообщить о выпуске. При проблеме вернуть предыдущую фронтенд-сборку; базу данных не трогать.

## Важные правила

- GitHub — журнал исходного кода и независимая резервная копия, но рабочий домен может обновляться напрямую через Timeweb.
- GitHub Pages собирается с базовым путём `/vkus-doma/`; Timeweb — с `/`. Это уже настроено в `vite.config.ts` и GitHub workflow.
- Нельзя чистить кэш браузера, PWA-хранилище или IndexedDB пользователей как способ «исправить обновление».
- Нельзя выполнять SQL-миграции одновременно с фронтенд-выпуском без отдельного миграционного плана и свежего дампа.
